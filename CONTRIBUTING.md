# Contributing

Thank you for helping improve Narrative Provenance.

Code is only one kind of contribution. The project also welcomes focused improvements to the platform-neutral workflow, templates, accessible presentation, language, examples, and neurodivergent design principles.

## Before opening an issue

- Search existing issues.
- Reproduce the problem in a separate test vault with the latest release.
- Remove private note content and identifying information.
- Include the Obsidian version, plugin version, platform, and concise reproduction steps.

## Pull requests

1. Create a focused branch.
2. Run `npm test` and `npm run build`.
3. Describe the user-facing behavior and any metadata changes.
4. Avoid new network access, telemetry, or dependencies unless the need and privacy impact are explicit.

By contributing, you agree that your contribution is licensed under the MIT License.

## Non-code contributions

- Test one template with fictional, public-domain, consensual, or safely redacted material.
- Report one confusing label or decision point.
- Suggest a clearer recovery message after interruption.
- Add a format adapter or teaching example without changing the canonical evidence distinctions.
- Review keyboard, touch, screen-reader, zoom, reflow, contrast, reduced-motion, cognitive-load, or mobile behavior.

Open a focused issue describing the context, what happened, what you expected, and the smallest change that might help. Do not post private vault contents, confidential correspondence, personal health information, or unredacted evidence.

## Presentation adaptations

The source in [`presentation/openai-event.md`](presentation/openai-event.md) is designed to be remade. Credit the original method and your adaptation separately, preserve the safety boundaries, and replace bracketed placeholders with your community's information. Adaptations must not imply affiliation with or endorsement by OpenAI, Obsidian, or any referenced person or organization.
